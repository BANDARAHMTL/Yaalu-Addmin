# Yaalu Admin Portal 🛡️

Operations & Management Admin Portal for the **Yaalu Multi-Vendor E-Commerce and Instant Delivery Platform**.

## Features 🚀
- **Executive KPI Dashboard**: Live tracking of Gross Revenue, Order Volume, Merchant Outlets, and Active Riders.
- **Merchant & Shop Verification**: Onboard, verify BR documents, review bank payout details, and manage shop statuses.
- **Delivery Fleet Management**: Verify rider licenses, vehicle registrations, and active dispatch states.
- **Global Catalog Management**: Real-time product inventory control with direct **Cloudinary CDN** asset uploading.
- **Order Dispatch Stream**: Monitor customer orders from pending to delivered stages.
- **Invoicing & Settlements**: Financial collection tracking, payment receipts, and billing history.
- **Customer Directory**: Central customer database with order frequency and lifetime spend metrics.

## Tech Stack 🛠️
- **Frontend Framework**: React 18 + TypeScript + Vite
- **Iconography**: Lucide Icons
- **Cloud Storage**: Cloudinary CDN (`yaalu` cloud)
- **Design System**: Custom Yaalu Dark Slate & Gold Theme

## Getting Started 💻
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
